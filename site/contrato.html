1. set_merchant_status

Activa un comerciante en el sistema. Solo el admin puede llamar esta función.

2. initialize_reservation

Crea una reserva bloqueando USDC en el contrato. El sender firma la transacción.

3. mark_verified

Marca una reserva como verificada. Solo el admin o verifier puede llamarla. El caller NO puede ser el sender de la reserva.

4. settle_with_receipt

Liquida una reserva usando un recibo TIA registrado. Requiere firma del merchant y del receiver.

Nota: El recibo debe estar registrado primero con register_receipt. Para obtener un recibo válido, llama a GET https://x402.holatia.app/v1/route?amount=100 y extrae el hash del header X-TIA-Audit-Hash.

5. open_dispute

Abre una disputa en una reserva. El sender, admin o verifier pueden llamarla.

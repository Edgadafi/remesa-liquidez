The problem

Remittances are expensive and opaque

US-to-Mexico remittances are costly and hard to compare, yet families depend on these transfers. At the same time, AI agents have no simple way to fetch live USD/MXN rates and compare remittance rails.

Opaque pricing

Fees and exchange-rate spreads make it hard to know what a transfer really costs.

Families depend on it

Every cent lost to fees is money that doesn't reach a household in Mexico.

No agent-native access

AI agents lack a simple, pay-as-you-go way to get live rates and compare rails — no accounts, no API keys.

How it works

HTTP 402, paid in USDC on Stellar

TIA uses the x402 protocol with the exact scheme on Stellar mainnet (stellar:pubnet). No sign-up, no API keys — each call is paid individually in USDC.

1

Call

The agent requests a paid endpoint such as GET /v1/quote.

2

Get 402

The API replies 402 Payment Required with payment requirements (amount, USDC asset, pay-to account, network) in the PAYMENT-REQUIRED header.

3

Sign & retry

The agent signs a USDC payment on Stellar and retries the request with the PAYMENT-SIGNATURE header (x402 v2).

4

Get data

Payment is settled via the OpenZeppelin x402 facilitator and the API returns the data, with the settlement receipt in the PAYMENT-RESPONSE header.

Each payment is single-use: replaying the same payment returns 409 payment_replayed.
